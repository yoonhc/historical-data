**1. 전체 백업과 복원 경로를 구현했다.**

등록된 원본·모든 표준 revision·고정 스냅샷·일관된 SQLite 카탈로그를 함께 백업한다.
수집기를 멈추지 않고 카탈로그를 고정할 때만 writer 잠금을 잡은 뒤 불변 파일을 복사한다.
파일 해시, 카탈로그 참조와 무결성을 검사하며, 완료 표시가 없는 불완전 백업은 복원 입력으로
사용하지 않는다. 복원은 기존 저장소를 덮어쓰지 않는 새 경로에서 수행한다.

최초 실데이터 백업은 10,487개 파일이었고 별도 경로 복원 후 스냅샷 20개와 데이터셋별
107개 조회 구간을 대조했다. 이후 aggTrade·depth·묶음 파일이 추가될 때마다 해당 자료를
포함한 백업·복원 호환성도 확인했다. 과거 format 1 백업은 계속 읽고, 묶음은 format 2로 보존한다.

**2. 선물 aggTrade 수집·공백 복구·값 검증을 구현했다.**

BTCUSDT USD-M 선물의 REST와 WebSocket aggTrade를 원문·수신 시각·출처와 함께 저장한다.
ID 누락·값 충돌·중복·순서 역전을 검사하고, 재접속·세션 전환 때 마지막 저장 ID부터
이어받아 제한된 REST 복구를 시도한다. 실패하거나 한도를 넘은 공백은 이력에 남긴다.

최초 REST 표본 9,138건에서 같은 10분의 기존 1분봉과 OHLC·거래량·거래대금·taker 매수량이
일치했다. 3분 WebSocket 표본에서는 연결 교체 중 누락 502건을 REST로 복구하고 공통 ID
6,533건의 값을 별도 조회와 대조했다. aggTrade 개수는 개별 체결 횟수와 같다고 취급하지 않는다.

REST 시간 조회는 최근 47시간 안의 최대 59분, 공백 복구는 최대 20페이지라는 현재 한도가 있다.
장기 aggTrade 아카이브 수집과 현물 스트림은 추가하지 않았다.

**3. 선물 depth 수집·호가 복원·재생을 구현했다.**

100ms 증분 스트림과 REST 최대 1,000단계 스냅샷을 연결한다. 처음에는 스냅샷 ID를 포함하는
증분을 찾고, 이후에는 `pu`와 직전 `u`의 연결을 검사한다. 수량은 절대량으로 적용하고 0은
삭제로 처리한다. 같은 업데이트 ID에서 독립 REST 스냅샷과 양쪽 상위 20호가를 대조한다.

원문과 표준 세그먼트를 다시 읽어 당시 호가·처리 건수·해시·오류를 재생한다. 최초 3분 표본의
1,729행, 가격·수량 334,553쌍과 독립 호가 대조 6회를 확인했다. 연결마다 새로운 동기화 구간
`epoch`를 만들며 연결 사이 공백을 복원했다고 표시하지 않는다. 전체 가격 범위나 RPI 주문의
완전한 호가장은 수집 범위가 아니다.

**5. 원문·표준 데이터의 무기한 보존과 파일 묶음을 구현했다.**

원문 gzip/JSON과 Parquet 바이트를 그대로 ZIP_STORED에 넣고 물리 위치만 카탈로그로 관리한다.

실제 적용 대상 파일 3,826개를 묶음 6개로 바꿨다. 원문·표준 파일의 해시와 ID, 오류 이력,

묶은 후에도 체결 감사·호가 재생·이전 실패 결과·백업 복원이 같음을 확인했다.

**6. 표본 수집을 상시 서비스와 자동 유지보수로 전환했다.**

2026-09-23 07:00:17 UTC / 16:00:17 KST부터 사용자 systemd에서 두 스트림 서비스를
활성화했다. 각각 1시간 세션을 반복하고 5초마다 저장하며, 종료 후 15초 뒤 재시작한다.

**남은 한계와 후속 범위**도 구분해 둔다.

1. depth의 연결·세션 경계와 장애 중 미복원 구간은 남는다. 증분 보존 성공, 호가 복원 성공,

   Freqtrade 체결·호가 소비 어댑터는 아직 추가하지 않았다.
3. 백업은 같은 파일시스템에 있다. 외부 장치·원격 백업과 외부 장애 알림은 연결하지 않았다.
   무기한 보존으로 데이터와 일별 백업은 계속 증가하며 용량·inode 관리는 계속 필요하다.
4. OI 단위·라벨·공개 지연과 완전한 시점별 가용성 재구성은 여전히 별도 검증 과제다.
5. 마지막 보존 운영 상태에는 2026-09-22 선물 거래봉·마크·지수·archive OI 일별 파일을
   확보하지 못한 4개 stale 항목이 있었다. 위 고정 과거 검증 종료 경계 이후의 하루이며,
   파일 무결성 통과나 호가 동기화 회복을 전체 운영 정상으로 해석하지 않는다.
