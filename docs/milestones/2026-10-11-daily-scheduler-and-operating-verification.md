**10/9 20:17 KST 이후 이번 정리까지 수행한 작업 전체**를 다룬다.

## 대상별 daily 구현·배포

최종 고정 실행본은 **`t13-daily-scheduler-20261011-703fb0d455523c1b`**다.
[이전 178개 검증 후보](../../reports/baseline/t13-daily-scheduler-2026-10-10/summary.md)를 보존하고,
[needs_review 재개·사본 미리보기 보완](../../reports/baseline/t13-daily-review-2026-10-10/summary.md)을 포함한
213개 검사와 깨끗한 비 editable 설치 재현을 완료했다. 같은 검사의 재현 횟수를 더해 검사 수를 부풀리지 않는다.

작업은 자료·시장·종목·주기·UTC 날짜·목적으로 고정한다. acquire/refresh/metadata 관측을 구분하고,
미확보 이월·시도·냉각·다음 시각·저장 근거를 영속 보존한다. 점검한 한 작업의 완료 연결 또는 추가 1~3회 재시도는
명시적 요청·상태 해시·처리 기록으로 한 번만 적용한다. 과거 실패·냉각·검증 기준을 우회하지 않는다.
`plan()`의 쓰기는 운영 DB 대신 일관된 사본에 한정했다. 네 미리보기 사본 약 18.11GiB는 별도 정리 검토로 남겼다.

[실제 배포](../../reports/baseline/t13-daily-deploy-2026-10-11/summary.md)는 다음 중단을 거쳐 완료했다.

- 00:42 설치 권한 검사 중단: uv가 복사한 쓰기 권한을 새 고정 배포본에서 제한하고 00:46 설치를 마쳤다.
- 00:49 timer 링크 검사 중단: disable로 제거된 base 링크를 변경 금지 파일로 취급한 오류를 보완했다.
  승인된 두 교체 경로와 기존 불변 guard를 구분하고 00:51 전환을 완료했다.
- 원래 실패·재개 코드·해시·receipt를 보존했다. scheduler 코드·정책을 바꾸거나 보호 검사를 없애지 않았다.

00:51:22 첫 실행 후 00:53:18 timer를 활성화했고 00:59까지 실제 실행 4회가 모두 성공했다.
기존 확보 156개 acquire를 연결하고 예정 전 refresh 18개·metadata 2개를 유지했다.
처리·수집 시도·공개 관측 요청은 0개이며 `runner_ok=true`, `data_complete=false`를 구분했다.
첫 runner는 17.465초, 후속 재평가는 0.262~0.289초였다. 모든 I/O·잠금 영향을 측정한 것은 아니다.

기존 사용자 daily만 새 `/opt` 실행본으로 옮겼다. 두 실시간 수집기·Chrony의 PID/invocation과 root guard·
boot/closed ledger·backup/pack/restic은 유지했다. 공개 관측기는 비활성, 자동 checkpoint 정리는 masked다.
