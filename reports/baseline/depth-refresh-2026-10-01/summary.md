## 완료한 구현·검증

- 조기 snapshot 검증: 남은 호가가 기준 개수의 75% 미만이거나 가격 여유가 기준 폭의
  25% 미만이면 정기 검증 전에도 요청한다. 최소 1초 간격, 한 수집의 최근 60초 추가 요청
  12회 상한이며 epoch·연결 변경에도 상한을 유지한다. 정상 대조에 성공한 snapshot만
  채택한다. 정기 검증·복구 anchor는 별도 계수이며 IP 전체의 공통 상한을 구현한 것은 아니다.
- 상위 N호가 부족: 부족한 상태와 원문을 보존하고 같은 연결의 새 epoch에서 anchor를 받는다.
  원래 ID 동기화 여부·불완전한 top·`partial`을 유지한다. 실제 값 불일치, ID 누락, 기존
  429/418 cooldown, 재생 검증 조건을 완화하지 않는다.
- 요청 전 flush 뒤 종료·회전 시각을 재확인한다. pending REST 후보가 있으면 추가 요청을
  보내지 않으며 요청 예산 때문에 수신 루프를 재우지 않는다.
- [전체 테스트](tests.xml): **411개 통과, 실패·건너뜀 0개**, 282.977초.
  기존 restic 0.19.1 바이너리를 격리 checkout에 복사해 실제 임시 저장소 테스트도 수행했다.
  네트워크 시험 IP 기본값을 8.8.8.8로 맞춘 뒤 관련 [15개 검사](network-final-tests.xml)도
  다시 통과했다. Ruff 검사·포맷, diff 공백 검사, 새 systemd 유닛 구문 검사도 통과했다.
- 독립된 전체 호가장을 정답으로 한 시험에서 빠른 잔량 소진, 순간적인 top 부족, 실제 수량
  불일치, 검증 대기, 시간 만료 중 flush, 429/418 중단 및 요청 상한을 확인했다.

## 네트워크 관측 적용

[설치 기록](network-install.json)에서 유닛 구문, 실행 사용자 `yoonhc`(UID 1000),
`/usr/bin/python3`, ip/ping/getent/curl 경로, 프로필 접근, `Linger=yes`를 확인했다.
기존 시장 수집·백업 관련 사용자 유닛과 restic 설정 파일의 설치 전후 해시는 일치한다.

실제 서비스 환경의 [첫 실행](network-first-service.json)은 **10/2 07:23:59 KST**에 성공했다.
07:26 기록까지 수동 서비스 1회와 타이머 실행 4회의 모든 probe가 정상이다.
타이머는 enabled/active이며 매분 20초에 실행한다. 설치 시 다음 예약은 07:24:20 KST였고,
이후 07:24:20·07:25:20·07:26:20 실행이 실제 기록됐다.
[실행 표본](network-running-sample.json)

이후 18:28 KST까지 [실제 관측 667회](network-followup.json)가 모두 정상이며 표본 간 최대
간격은 60.259초다. [현재 수집기 표본](collectors-followup.json)도 정상 수신 상태다.
이는 기록된 표본의 결과이며 과거 10/1 통신 장애의 물리적 원인을 확정하는 증거는 아니다.

외부 숫자 IP는 사전 시험에서 응답한 8.8.8.8:443으로 설정했다. 1.1.1.1:443의 시간 초과는
해당 목적지의 도달성 결과이며 전체 인터넷 장애로 판단하지 않았다. 프로필은 머신 밖으로
이전할 때 바꿀 수 있다. probe의 TLS·HTTP 성공은 WebSocket 구독과 실제 수신 성공의 대체
지표가 아니며, 1분 사이의 짧은 장애나 OS 이름 해석 캐시를 구분할 충분한 증거는 아니다.

```bash
systemctl --user list-timers marketdata-network-observer.timer
systemctl --user show marketdata-network-observer.service --property=Result,ExecMainStatus
python3 -m json.tool reports/network-observer/latest.json
python3 -m json.tool reports/baseline/depth-refresh-2026-10-01/activation.json
```
